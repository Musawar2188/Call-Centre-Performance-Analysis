## Project Overview
This project provides a comprehensive analysis of Call Centre operations. It tracks key performance indicators (KPIs) like total calls, average duration, and response time percentages to improve operational efficiency.

## Key Insights
* **Total Volume:** Analyzed over 32,000 calls with a total duration of 13.74K hours.
* **Customer Sentiment:** Visualized sentiment distribution from "Very Negative" to "Very Positive."
* **Geographic Analysis:** Identified Los Angeles as the highest volume center with 14K calls.
* **Top Issues:** Billing questions were the primary reason for calls.

## Tools Used
* **Power BI:** For data visualization and dashboarding.
* **Excel/CSV:** Used as the primary data source.
